## Overview

Loud Gadgets is a full-featured e-commerce storefront for a premium tech retailer in Enugu, Nigeria. Browse products, filter by category, add to cart, and check out — all in a responsive, accessible experience.

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | Next.js 16 (App Router) |
| Styling | Tailwind CSS |
| Animation | Framer Motion |
| State | React Context + localStorage |
| Deployment | Vercel |

## Features

- Product catalog with category filtering
- Live shopping cart with quantity controls
- Responsive layout (mobile → desktop)
- Search with live result filtering
- WCAG 2.1 AA accessible

## Getting Started

```bash

npm run dev
```
